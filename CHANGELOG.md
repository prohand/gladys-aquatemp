## [Unreleased]

### Added

- First version of the Aqua Temp integration: heat pumps of an Aqua Temp or Hi Temp account (own
  and shared) through the Aqua Temp cloud.
- Devices: power, mode (cooling / heating / auto), setpoint per mode, silent mode, water inlet,
  water outlet and outdoor temperatures; cloud / unreachable transport badge.
- Scene triggers: fault detected, fault cleared, heat pump online or offline.
- Scene actions: set the mode (off included), set the silent mode, read the status.
- "Heat pump" dashboard widget: live temperatures, cloud status, mode, silent mode, fault, and
  Turn on / Turn off and Refresh buttons.
- "Test the connection" button in the configuration screen.
- English, French, German and Spanish texts and documentation; catalog keywords and countries.
